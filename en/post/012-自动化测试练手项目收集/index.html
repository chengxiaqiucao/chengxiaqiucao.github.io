Projects Suitable for Practicing Test Automation

Some recommended projects suitable for practicing test automation

Sep 20, 2024
2 minute read
中文

Many friends who are new to test automation have read a lot of tutorials, but are troubled by not having suitable projects to practice with. Here the author would like to share some good practice projects that have been collected.

DemoQA

DemoQA is a practice website specifically designed for practicing web test automation such as Selenium. It covers all kinds of commonly used elements and controls in the process of learning Web automation, allowing a fairly comprehensive study of page handling.

The-internet

The-Internet is also a project aimed at beginners, specifically for test automation practice, and is quite similar to DemoQA. The scenarios can complement each other. Besides using it online, you can also download the source code from its GitHub project and deploy it yourself (based on Ruby).

SauceLab App

SauceLab is a testing service provider, and SauceDemo is a site it provides for test automation practice.

In addition to the Web version, this project also provides a mobile version, my-demo-app, which can be used for practicing Android/IOS application test automation, and can be obtained through SauceLab’s GitHub project.

https://github.com/saucelabs/my-demo-app-android

https://github.com/saucelabs/my-demo-app-ios

Sahi Test

Sahi Test is a project self-built by a testing blogger for test automation practice, containing very rich scenarios.

GURU99 Demo

Demo Guru99 is a collection of multiple projects integrated by the Guru99 website for test automation practice, including insurance, banking, telecommunications, and the Tour project that comes with the traditional test automation tool QTP.

JpetStore

JpetStore is a pet store application provided by mybatis. Project address: https://github.com/mybatis/jpetstore-6

OpenCart

Besides the projects above that are specifically provided for test automation practice, we can also find some more fully featured open source free sites to use when practicing.

For example, OpenCart is an open source e-commerce website, and you can practice based on its Demo site.

OrangeHRM

OrangeHRM is a powerful open source HR management system, and it is likewise a very good choice as a practice site for test automation.

The above are some commonly used websites collected and organized by the author that can be used for test automation practice. Of course, there are in fact a large number of fairly mature web applications on open source sites, and we can absolutely set them up locally before practicing. If you have any other good practice projects to recommend, feel free to add them in the comments~~

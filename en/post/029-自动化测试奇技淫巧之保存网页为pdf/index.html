A Test Automation Trick: Saving Web Pages as PDF

A simple way to save web pages as PDF with Puppeteer when you find valuable material online.

Oct 03, 2024
4 minute read
中文

When browsing material on websites, we often come across valuable documents that we need to save. Copying the content directly is actually rather troublesome, and some sites even impose restrictions that make saving inconvenient. In such cases, saving the page directly as a PDF file is a very useful requirement.

The usual approach relies on browser extensions or printing add-ons. Since we are learning automation here, we can in fact use Puppeteer to achieve this conveniently. Combined with the power of automation, it is absolutely a great tool for crawling and saving important material.

Puppeteer Usage

For the basic usage of the Puppeteer tool, I already gave a fairly comprehensive introduction in my earlier post An Introduction to Puppeteer for Test Automation, which you can refer to.

Basic Usage of pdf()

Saving a PDF file in Puppeteer is actually very simple. By calling Puppeteer’s built-in pdf() method, you can save the current page as a PDF file.

The official example:

(async () => {
  const browser = await puppeteer.launch();
  const page = await browser.newPage();
  await page.goto('https://news.ycombinator.com', {
    waitUntil: 'networkidle2',
  });
  await page.pdf({
    path: 'hn.pdf',
    format: 'letter',
  });

  await browser.close();
})();

It is used to visit a tech news aggregation site and save the page to the hn.pdf file.

PaperFormat

In the example above there is a format parameter. This parameter actually specifies the page size to save, and it can take a number of default print page sizes. The list of values and their corresponding sizes is as follows (in inches):

  • Letter: 8.5in x 11in
  • Legal: 8.5in x 14in
  • Tabloid: 11in x 17in
  • Ledger: 17in x 11in
  • A0: 33.1102in x 46.811in
  • A1: 23.3858in x 33.1102in
  • A2: 16.5354in x 23.3858in
  • A3: 11.6929in x 16.5354in
  • A4: 8.2677in x 11.6929in
  • A5: 5.8268in x 8.2677in
  • A6: 4.1339in x 5.8268in

PDFMargin

Besides format, you can also set page margins as you would when printing, by setting the margin property. The corresponding values are:

  await page.pdf({
    path: 'hn.pdf',
    format: 'A4',
    margin: {'left': 80, 'top': 40},
  });

You can see that the margins have also been adjusted.

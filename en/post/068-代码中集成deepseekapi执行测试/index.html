Integrating the DeepSeek API into Code to Run Tests

Taking the integration of DeepSeek's official API as an example, a hands-on practice of calling a large model from code to automatically generate test cases and execute them

Mar 19, 2025
3 minute read
中文

In a previous article

Automatically Generating Test Scripts with DeepSeek + VS Code

we introduced an AI plugin for VS Code that helps us automatically generate test cases.

Now the official DeepSeek API has reopened as well, offering more possibilities for deeply leveraging large models such as DeepSeek to build applications that fit real-world work.

Below, taking the integration of DeepSeek’s official API as an example, we will walk through a practice of calling a large model from code to automatically generate test cases and execute them.

First, head to the API open platform from the official DeepSeek website

Once there, apply for an API key. DeepSeek’s pricing is still fairly low at the moment, and there are sizable discounts during certain hours.

With this API key, we can start calling it from our code.

The DeepSeek API is currently compatible with the OpenAI API interface.

With the code below, combined with Python’s standard library inspect, we can have DeepSeek generate test cases directly against our code under test.

Of course, we can also feed the corresponding requirements text to DeepSeek; the principle is similar.

import inspect
from openai import OpenAI

# Import the DeepSeek API
client = OpenAI(api_key="<your_deepseek_api_key>", base_url="https://api.deepseek.com")


# Function under test, calculates BMI
def calculate_bmi(weight, height):
    if height <= 0 or weight <= 0:
        raise ValueError("身高、体重必须大于0")
    bmi = weight / (height ** 2)
    if bmi < 18.5:
        return "竹竿！"
    elif 18.5 <= bmi < 24.9:
        return "正常人"
    elif 25 <= bmi < 29.9:
        return "壮士！"
    else:
        return "肥宅！"

# Get the function's source code via inspect
function_code = inspect.getsource(calculate_bmi)

# Define the prompt based on the retrieved code
the_prompt = f"""
请针对以下代码生成基于pytest框架的测试用例：{function_code}
尽可能使用参数化测试，包含各种异常场景

"""

# Call the DeepSeek API using the V3 model and get the response
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "system", "content": "You are a python testing assistant"},
        {"role": "user", "content": the_prompt},
    ],
    max_tokens=1024,  
	temperature=0.7
    stream=False
)

print(response.choices[0].message.content)

To test the `calculate_bmi` function, we can use the `pytest` framework together with `pytest.mark.parametrize` to implement parameterized testing. Below is a complete test case covering both normal and exceptional scenarios.

 ```python
import pytest

# Import the function under test
from your_module import calculate_bmi

# Test cases for normal scenarios
@pytest.mark.parametrize("weight, height, expected", [
    (60, 1.75, "正常人"),  # Normal BMI
    (50, 1.75, "竹竿！"),  # Low BMI
    (80, 1.75, "壮士！"),  # High BMI
    (100, 1.75, "肥宅！"),  # Very high BMI
])
def test_calculate_bmi_normal(weight, height, expected):
    assert calculate_bmi(weight, height) == expected

# Test cases for exceptional scenarios
@pytest.mark.parametrize("weight, height, expected_exception", [
    (0, 1.75, ValueError),  # Weight is 0
    (60, 0, ValueError),    # Height is 0
    (-10, 1.75, ValueError), # Weight is negative
    (60, -1.75, ValueError), # Height is negative
])
def test_calculate_bmi_exceptions(weight, height, expected_exception):
    with pytest.raises(expected_exception):
        calculate_bmi(weight, height)
` ``

### Explanation:
1. **Normal scenario tests**:
   - Use `pytest.mark.parametrize` to test different combinations of weight and height, verifying that the BMI category returned by the function is correct.
   - The test cases cover normal BMI, low BMI, high BMI, and very high BMI.

2. **Exceptional scenario tests**:
   - Verify that the function raises a `ValueError` when given invalid inputs (such as weight or height being 0 or negative).
   - Use `pytest.raises` to catch the expected exception.

### Running the tests:
Make sure you have `pytest` installed, then run the following command in the terminal to execute the tests:

```bash
pytest test_bmi.py
` ``

### Notes:
- `your_module` is the name of the module containing the `calculate_bmi` function; replace it with the actual one.
- Test files are usually named `test_*.py` or `*_test.py` so that `pytest` can discover and run them automatically.

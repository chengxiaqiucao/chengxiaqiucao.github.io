Preface

In an earlier article about image handling in Markdown documents 【How Should Images Be Handled When Publishing Locally Written Markdown Documents to the Web?】, we introduced the use of AutoHotKey to assist with screenshots and automatic link generation. Some readers sent private messages asking about the concrete usage of this tool.

Below, we will introduce this tool in a fairly systematic way and see how the scripting magic of AHK can make repetitive operations happen with a single keystroke!

AHK Introduction

In software development and technical work that pursues efficiency, repetitive operations often devour precious time. AutoHotkey (AHK), as a lightweight, open-source Windows desktop automation tool, can free users from tedious, repetitive keyboard and mouse operations through concise scripts, significantly boosting productivity.

The key to understanding AHK lies in its scripting language. Core features include simulating keyboard input (Send), mouse operations (Click), running programs (Run), conditional judgment (If), and loop control (Loop), among others. Users need no compilation environment; script files (.ahk) can run directly with extremely low resource usage.

AHK’s application scenarios are extremely broad. Simple ones include auto-filling forms and quickly inserting preset phrases; more advanced ones include batch-renaming files, automated software testing, and customizing dedicated workflows; it can even be used to develop small tools with a graphical user interface (GUI). Its power lies in deep integration with the Windows system, enabling it to manipulate windows, read and write the registry, and access the file system for a high degree of customized automation.

Simply put, AutoHotKey gives users the ability to command the computer with scripts. Whether you are a developer, an office worker, or an everyday user who values efficiency, you can use it to customize your own “shortcut magic,” turning repetitive labor into automation that completes in an instant.

AHK Core Syntax and Common Functions

**Basic Hotkeys

  • Hotkey Definition - Consists of a hotkey followed by a double colon.
1
2
3

^j::  ; Ctrl+J hotkey
	Send, Hello World!  ; send text
	return

If there is only a single line of action to execute, return can also be omitted.

SymbolDescription
#Win key (Windows logo key)
- Send text after Win is released (Vista+)
- May cause extra simulated keystrokes (see #MenuMaskKey)
!Alt key
- May cause extra simulated keystrokes (see #MenuMaskKey)
^Ctrl key
+Shift key
&Combine any two keys/mouse buttons to create a custom hotkey
<Use the left key of a pair (e.g. <!a triggers only with left Alt)
>Use the right key of a pair
<^>!AltGr key (alternate graphic key)
- Represents AltGr combinations (e.g. <^>!m)
- Used alone: LControl & RAlt
*Wildcard: triggers even when extra modifier keys are held
- Example: *#c (Win+C / Shift+Win+C etc. all trigger)
- Forces use of the keyboard hook
~Keeps the key’s native function (does not block OS events)
- Example: ~RButton (right-click is still sent to the window)
- Affects all combination behavior
- Forces use of the keyboard hook
$Forces use of the keyboard hook to prevent the Send command from triggering itself
- Has no effect on mouse hotkeys
- Alternative: #InputLevel / SendLevel (v1.1.06+)
UPTriggers on key release (not on press)
- Example: ^!r Up:: (triggers on releasing Ctrl+Alt+R)
- Limitations:
1) Does not apply to controller buttons
2) Must be paired with a normal hotkey to avoid stuck keys

Example

1
2
3
4
5
6

#a::Run Calculator              ; Win+A launches Calculator
^!+s::Send Hello World         ; Ctrl+Alt+Shift+S sends text
~RButton::MsgBox Right Click   ; Message box that keeps the right button's native function
LWin & R::Reload               ; Left Win+R reloads the script
*#c::Run cmd.exe               ; Any modifier + Win+C launches the command prompt
^!r Up::MsgBox Released       ; Triggers when the combination is released

Hotstrings

  • Hotstring - Consists of a colon, zero or more options, another colon, the abbreviation characters, and a double colon.
1

:*:btw:: by the way  ; replaces after typing btw and pressing space/enter

Alternatively, you can also use hotstrings to perform somewhat more complex operations.

1
2
3
4

:*:]d::  ; This hotstring uses the following commands to replace "]d" with the current date and time.
FormatTime, CurrentDateTime,, M/d/yyyy h:mm tt  ; 
SendInput %CurrentDateTime%
return

Practical Use Cases

Case 1 - Automatically Generate Markdown Image Links from Screenshots

Pain point - Manual screenshot → save → copy path → insert into Markdown is tedious Solution - Complete the screenshot and generate a standard link with one key

 1
 2
 3
 4
 5
 6

10
11
12
13

#s::  ; Win+S shortcut
    Run, %A_WinDir%\System32\SnippingTool.exe  ; launch the screenshot tool
    WinWaitActive, Snip & Sketch  ; wait for the window to become active
    Send, ^+n  ; simulate the new-screenshot shortcut (Ctrl+Shift+N)
    WinWaitActive, ahk_class Microsoft.ScreenSketch  ; wait for the screenshot to complete
    Send, ^s  ; save the screenshot
    WinWaitActive, Save As  ; wait for the save dialog
    FormatTime, CurrentTime,, yyyyMMdd_HHmmss  ; generate a timestamp filename
    SendInput, %CurrentTime%.png{Enter}  ; enter the filename
    Sleep, 1000  ; wait for the save to complete
    clipboard := "![](" . A_Desktop . "\" . CurrentTime . ".webp)"  ; generate the MD link
    MsgBox, Markdown screenshot link copied to clipboard!
return

Effect - Press Win+S → screenshot → automatically save as a timestamped PNG → the clipboard generates a link in the ![](路径) format.

^!d::  ; Ctrl+Alt+D

    WinWaitActive, ahk_class ConsoleWindowClass

F9::
    testData := ""
    Loop, 100 {  ; generate 100 records
        name := "User" . A_Index
        email := "user" . A_Index . "@test.com"
        age := Random(18, 60)  ; custom Random function generates a random number
        testData .= name "," email "," age "`n"  ; concatenate in CSV format
    }
    FileAppend, %testData%, C:\TestData\users.csv  ; write to file
    Run, notepad.exe C:\TestData\users.csv  ; open to view
return

Random(min, max) {
    Random, rand, min, max
    return rand
}

Effect - Press F9 to automatically generate 100 CSV test records containing username, email, and age.

Summary - Why Use AutoHotKey?

  1. Minimal learning curve - Syntax close to natural language, no compilation environment needed
  2. Resource friendly - Lightweight (installer < 3MB), negligible background footprint
  3. Deep integration - Seamlessly manipulate windows, the registry, and the file system
  4. Rich ecosystem - The official forum offers a vast script library and plugin support
  5. Cross-scenario - Full coverage from text processing to GUI automation

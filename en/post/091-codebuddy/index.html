Cursor Charges Money? No Worries, We Still Have CodeBuddy!

May 09, 2025
17 minute read
中文

Previously we introduced generating automated test code with AI, as well as controlling a browser through an mcp server, using the AI programming IDE Cursor. With its powerful intelligent analysis and assisted-programming capabilities, Cursor can automatically complete the code implementation for us when we describe a programming requirement in natural language; it is efficient and works very well. But Cursor is not free software; once the trial period ends, using it as a daily tool is still rather expensive.

But now Tencent has also stepped in and launched a code assistant, the very protagonist of this article, CodeBuddy. Its programming capability is in no way inferior to Cursor’s, and it even has a halo bonus for applications within the Tencent ecosystem such as Mini Programs. More importantly, it is completely free!

Installation

CodeBuddy itself does not provide a standalone IDE, but it offers plugin support for all the mainstream IDEs

Search for “Tencent Cloud Code Assistant” in the plugin marketplace of each development tool and you will find the corresponding plugin; just install it accordingly

Taking VS Code as an example, once the plugin is installed, open the plugin panel and you can get programming assistance similar to the assistant pages of Copilot or Cursor. In CodeBuddy, this is called Craft mode

Besides this mode of assisting with code generation, there is also a Chat mode, which allows conversational interaction much like generative AI.

In addition, Code Review mode helps with reviewing existing code, while Unit Test automatically writes unit test scripts for the current code.

Hands-on Mini Program Development

And since CodeBuddy itself is built on the Tencent ecosystem, for work like Mini Program development it enjoys a natural built-in advantage.

Here, after installing the CodeBuddy plugin in WeChat Developer Tools, with just a few interactive Q&A rounds, it helped me complete the implementation of a Mini Program.

Below is the implementation I completed with it, which fetches the most popular GitHub repositories of the past month. It took roughly a bit over ten minutes in total, and in actual testing it works and the interface is friendly.

In the future, perhaps everyone really will be a developer; even without knowing much about programming, as long as you have an idea, you can easily turn it into reality!
